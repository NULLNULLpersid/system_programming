# 파일 추가 프로그램
## 문제 설명
- 아래의 내용을 살펴보고 cat 프로그램을 확장하세요.
    1. 실습 1번 cat 프로그램을 기반으로 확장하세요.
    2. 확장 사항
        - 명령어 인수로 여러 개의 파일을 받으면 순차적으로 파일 내용 출력
        - -n 옵션은 파일 내용을 줄 번호와 함께 출력
    
- 실행 명령어
    1. 여러 개 파일
        - gcc –o cat cat.c
        - ./cat file1.txt file2.txt file3.txt
    2. 줄번호 함께 출력
        - gcc –o cat cat.c
        - ./cat –n file.txt
