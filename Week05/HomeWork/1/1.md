# 사용자가 원하는 줄 출력하기
## 문제 설명
- 이 프로그램을 시작하면 프롬프트를 내주며 사용자가 원하는 줄 번호를 입력 받아 해당 줄을 줄번호와 함께 출력한다.
-  번호는 다음과 같은 다양한 형태로 입력할 수 있다.
    - n : 한 줄 번호
    - n, …, m : 줄 번호 리스트
    - n-m : 줄의 범위
    - * : 모든 줄
- 텍스트 파일은 아래와 같이 에디터로 작성 하여 test.txt 로 저장
    - This is the week4 subtask
    - This task is number1
    - thank you
    - .
## 문제 힌트
- 우선 텍스트 파일의 모든 문자열을 2차원 배열에 저장해 놓은 후, 입력 값으로 라인 번호가 입력 됐을 때 각 조건에 따라 2저장된 2차원 배열에서 출력 하면 됨

1. 텍스트 파일의 각 문자열을 저장할 2차원 배열을 생성
    - char savedText[10][100];
    - 가변 데이터를 사용하고 싶으면 더블포인터 사용해도 됨

2. 차원 배열(savedText)의 각 행에 문자열을 저장
    - Read()함수를 이용해서 문자 '\n'가 나올 때 까지 배열의 각 열에 1바이트씩 저장하면 됨
    - '\n'가 나오면 다음 줄로 이동
    - 예) 아래 예제와 같이 read와 저장 과정을 '\n'나올때까지 반복하면 한줄 입력 완료
        - char buf;
        - Read(fd, &buf, 1);
        - saveText[0][0] = buf;
        - Read(fd, &buf, 1);
        - saveText[0][1] = buf;
3. 모든 텍스트 파일 저장 완료 후, 입력 옵션에 따라 해당 라인 출력
    - 예) 
        - 입력값 : 1
        - 출력 : Printf(“%s\n”,savedText[1])

## 채점
- 아래 각 옵션에 따라 단계별로 실습 점수 부여 함
    - n 한 줄 번호 1점
    - n, …, m 줄 번호 리스트. 2점
    - n-m 줄의 범위 3점
    - * 모든 줄 5점
